# Lumivex Solutions — GitHub Pages web stranica

Ovo je kompletna statička web stranica spremna za upload na GitHub Pages.

## Sadržaj

- `index.html` — glavna stranica
- `projekti.html` — zasebna stranica za buduće projekte
- `404.html` — stranica za grešku
- `.nojekyll` — sprječava Jekyll obradu na GitHub Pages
- `assets/css/style.css` — kompletan dizajn
- `assets/js/main.js` — mobilni izbornik, animacije i godina u footeru
- `assets/images/` — logo, favicon i generirani premium branding vizuali

## Upload na GitHub

1. Otvori repozitorij `Lumivex-solutions`.
2. Izbriši stare datoteke ako želiš krenuti potpuno ispočetka.
3. Upload-aj **sadržaj ove mape**, ne samu ZIP datoteku.
4. Obavezno neka `index.html` bude u glavnom/root direktoriju repozitorija.
5. U GitHubu idi na **Settings → Pages**.
6. Pod **Build and deployment** odaberi **Deploy from a branch**.
7. Odaberi branch `main` i folder `/root`, zatim spremi.

## Napomena o slikama

Slike u ovoj verziji su generirani branding vizuali za prezentaciju identiteta stranice. Nisu prikazane kao stvarni izvedeni projekti. Stvarni projekti su predviđeni na zasebnoj stranici `projekti.html`.
